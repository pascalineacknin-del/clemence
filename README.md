# Projet Clémence

Ceci est un projet de démarrage pour **Clémence**.

## Utilisation

1. Ouvrir un terminal dans le dossier `clemence`
2. Copier votre page HTML dans `index.html`
3. Si nécessaire, exécuter `npm install`

## Déploiement sur Vercel

1. Créez un projet Vercel à partir du dossier `clemence`
2. Déployez le site statique
3. Dans les paramètres du projet Vercel, ajoutez votre domaine personnalisé `clemencejobtravel`
4. Configurez l'enregistrement DNS `A` ou `CNAME` fourni par Vercel pour votre domaine

## Contenu

- `index.html` : page HTML hébergée
- `vercel.json` : configuration Vercel simple
- `package.json` : configuration du projet
